==================================================
COMMANDS TO RUN CARDIOVASCULAR DISEASE RISK APP
==================================================

METHOD 1: RUN BOTH FRONTEND & BACKEND CONCURRENTLY (RECOMMENDED)
----------------------------------------------------------------
1. Open terminal in the project root directory:
   cd D:\ML_Cardiovascular_Disease-main

2. Install dependencies (if not done yet):
   pip install -r requirements.txt
   npm install

3. Run both Backend & Frontend together:
   npm run dev

   (Backend runs on http://localhost:8000 | Frontend runs on http://localhost:5173)


==================================================
METHOD 2: RUN BACKEND AND FRONTEND IN SEPARATE TERMINALS
==================================================

--- TERMINAL 1: BACKEND (FastAPI Server) ---
1. Open a new terminal and navigate to the project directory:
   cd D:\ML_Cardiovascular_Disease-main

2. Start the Backend server using python -m uvicorn:
   python -m uvicorn api.index:app --reload --port 8000

   *Note: Using 'python -m uvicorn' avoids PATH issues on Windows.*
   (Backend API will be live at http://localhost:8000)


--- TERMINAL 2: FRONTEND (Vite React UI) ---
1. Open a second terminal and navigate to the project directory:
   cd D:\ML_Cardiovascular_Disease-main

2. Start the Frontend development server:
   npm run dev:frontend

   (Frontend web app will be live at http://localhost:5173)
